# icravehq-legal

Static HTML pages for [icravehq.com](https://icravehq.com) — hosted via GitHub Pages.

## Pages

| File | URL |
|------|-----|
| `index.html` | icravehq.com/ |
| `privacy.html` | icravehq.com/privacy |
| `terms.html` | icravehq.com/terms |
| `support.html` | icravehq.com/support |

## Updating Content

Edit the relevant `.html` file, commit, and push to `main`. GitHub Pages deploys automatically within ~60 seconds.

## DNS

Custom domain is set via the `CNAME` file (`icravehq.com`). DNS is managed at Spaceship. Do not delete the CNAME file.

## Notes

- `styles.css` is shared across all pages — edit once, applies everywhere.
- `favicon.png` is a 32×32 crop of the iCrave app icon.
- This repo is intentionally public. Legal documents are public-facing content.
